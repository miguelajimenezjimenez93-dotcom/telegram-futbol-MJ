
# Bot Telegram Alertas Fútbol

Bot automático para:
- Convocatorias
- Lesiones
- Bajas de última hora
- Sanciones

## PASOS RÁPIDOS DESDE EL MÓVIL

### 1. Crear bot
Habla con BotFather:
https://t.me/BotFather

Usa:
`/newbot`

Guarda el TOKEN.

---

### 2. Crear canal privado
Añade el bot como administrador.

---

### 3. Sacar CHAT_ID
Entra en:

https://api.telegram.org/botTU_TOKEN/getUpdates

Envía un mensaje al canal antes.

---

### 4. Crear API deportiva
https://www.api-football.com/

Guarda tu API KEY.

---

### 5. Subir a Railway
https://railway.app/

- Crear proyecto
- Subir estos archivos
- Añadir variables:

TELEGRAM_TOKEN
CHAT_ID
API_KEY

---

### 6. Deploy
Pulsa Deploy y listo.

El bot quedará funcionando 24/7.
